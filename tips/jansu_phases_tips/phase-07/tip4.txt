## 1. Finish the record-batch codec and validation path

Phase 07 explicitly requires gzip, snappy, lz4, and zstd according to Kafka record-batch behavior. The `Compression` enum already includes `Snappy`, and the inflator path has snappy decode support, but the deflation path currently only writes none/gzip/lz4/zstd and returns `UnexpectedType` for anything else.   The `snap` crate is already a dependency, so this is a direct implementation gap rather than a dependency gap. 

### Change: add snappy deflation

**File:** `jansu-sans-io/src/record/deflated.rs`

Add a `Compression::Snappy` branch in `into_record_data`:

```rust
fn into_record_data(records: &[Record], compression: Compression) -> Result<Bytes> {
    let sizing = records
        .iter()
        .map(|record| record.size_in_bytes())
        .collect::<Result<Vec<_>>>()?
        .iter()
        .sum::<usize>();

    debug!(sizing);

    let uncompressed = || records.encode();

    match compression {
        Compression::None => records.encode(),

        Compression::Gzip => {
            let uncompressed = uncompressed()?;

            let mut gz = GzEncoder::new(
                BytesMut::with_capacity(uncompressed.len()).writer(),
                flate2::Compression::default(),
            );

            gz.write_all(&uncompressed)?;

            gz.finish()
                .map(|w| w.into_inner())
                .map(Bytes::from)
                .map_err(Into::into)
        }

        Compression::Snappy => {
            let uncompressed = uncompressed()?;

            let mut encoder = snap::raw::Encoder::new();
            encoder
                .compress_vec(&uncompressed)
                .map(Bytes::from)
                .map_err(Into::into)
        }

        Compression::Lz4 => {
            let uncompressed = uncompressed()?;

            let mut lz4 = lz4::EncoderBuilder::new()
                .build(BytesMut::with_capacity(uncompressed.len()).writer())?;

            lz4.write_all(&uncompressed[..])?;

            let (w, _) = lz4.finish();
            Ok(Bytes::from(w.into_inner()))
        }

        Compression::Zstd => {
            let uncompressed = uncompressed()?;

            let mut zstd = zstd::stream::write::Encoder::new(
                BytesMut::with_capacity(uncompressed.len()).writer(),
                0,
            )?;

            zstd.write_all(&uncompressed[..])?;

            zstd.finish()
                .map(|w| w.into_inner())
                .map(Bytes::from)
                .map_err(Into::into)
        }
    }
}
```

## 2. Replace canonical re-compression CRC validation with direct CRC validation

The current `ProduceService::validate_batch` inflates the batch and re-deflates it, then compares canonical `batch_length` and `crc`. That catches corruption, but it is too strict for a Kafka-compatible broker because a producer’s compressed bytes can be valid without being byte-identical to Jansu’s recompression output. This especially matters once snappy client fixtures are added.

### Change: expose direct batch length and CRC checks

**File:** `jansu-sans-io/src/record/deflated.rs`

Add methods on `Batch`:

```rust
impl Batch {
    pub fn expected_batch_length(&self) -> Result<i32> {
        i32::try_from(FIXED_BATCH_LENGTH + self.record_data.len()).map_err(Into::into)
    }

    pub fn computed_crc(&self) -> Result<u32> {
        CrcData::from(self).crc()
    }

    pub fn validate_crc(&self) -> Result<()> {
        let computed = self.computed_crc()?;

        if computed == self.crc {
            Ok(())
        } else {
            error!(stored = self.crc, computed);
            Err(Error::ApiError(ErrorCode::CorruptMessage))
        }
    }
}
```

If `jansu_sans_io::Error::ApiError(ErrorCode)` is not currently used in this path, use `Error::Message("corrupt record batch crc".into())` and map that to `CorruptMessage` in `ProduceService`. The key is that CRC validation must be against the original received bytes, not against recompressed bytes.

### Change: use direct validation in ProduceService

**File:** `jansu-storage/src/service/produce.rs`

Replace the canonical re-deflation block in `validate_batch` with direct checks:

```rust
fn validate_batch(batch: &deflated::Batch) -> Result<()> {
    let attributes =
        BatchAttribute::try_from(batch.attributes).map_err(|error| match error {
            jansu_sans_io::Error::UnknownCompressionType(_) => {
                Error::Api(ErrorCode::UnsupportedCompressionType)
            }
            otherwise => Error::from(otherwise),
        })?;

    if batch.magic != Self::MAGIC_V2 {
        return Err(Error::Api(ErrorCode::InvalidRecord));
    }

    if batch.batch_length < 0 {
        return Err(Error::Api(ErrorCode::CorruptMessage));
    }

    let expected_batch_length = batch.expected_batch_length().map_err(|error| {
        debug!(?error);
        Error::Api(ErrorCode::CorruptMessage)
    })?;

    if batch.batch_length != expected_batch_length {
        return Err(Error::Api(ErrorCode::CorruptMessage));
    }

    batch.validate_crc().map_err(|error| {
        debug!(?error);
        Error::Api(ErrorCode::CorruptMessage)
    })?;

    if batch.base_timestamp < 0
        || batch.max_timestamp < 0
        || batch.max_timestamp < batch.base_timestamp
    {
        return Err(Error::Api(ErrorCode::InvalidTimestamp));
    }

    if attributes.control {
        return Err(Error::Api(ErrorCode::InvalidRecord));
    }

    if attributes.delete_horizon {
        return Err(Error::Api(ErrorCode::InvalidRecord));
    }

    if attributes.transaction {
        // Phase 12 owns transactional visibility and EOS. Until then, transactional
        // Produce must fail truthfully instead of being silently accepted.
        return Err(Error::Api(ErrorCode::InvalidTxnState));
    }

    let records: Vec<Record> = batch.try_into().map_err(|error| {
        debug!(?error);
        Error::Api(ErrorCode::CorruptMessage)
    })?;

    Self::validate_records(batch, attributes, &records)
}
```

Add a helper:

```rust
fn validate_records(
    batch: &deflated::Batch,
    attributes: BatchAttribute,
    records: &[Record],
) -> Result<()> {
    if records.is_empty() {
        return Err(Error::Api(ErrorCode::InvalidRecord));
    }

    let expected_record_count =
        u32::try_from(records.len()).map_err(|_| Error::Api(ErrorCode::InvalidRecord))?;

    if batch.record_count != expected_record_count {
        return Err(Error::Api(ErrorCode::InvalidRecord));
    }

    let expected_last_offset_delta =
        i32::try_from(records.len() - 1).map_err(|_| Error::Api(ErrorCode::InvalidRecord))?;

    if batch.last_offset_delta != expected_last_offset_delta {
        return Err(Error::Api(ErrorCode::InvalidRecord));
    }

    for (index, record) in records.iter().enumerate() {
        let expected_offset_delta =
            i32::try_from(index).map_err(|_| Error::Api(ErrorCode::InvalidRecord))?;

        if record.offset_delta != expected_offset_delta {
            return Err(Error::Api(ErrorCode::InvalidRecord));
        }

        if record.timestamp_delta < 0 {
            return Err(Error::Api(ErrorCode::InvalidTimestamp));
        }

        let timestamp = batch
            .base_timestamp
            .checked_add(record.timestamp_delta)
            .ok_or(Error::Api(ErrorCode::InvalidTimestamp))?;

        if timestamp < batch.base_timestamp {
            return Err(Error::Api(ErrorCode::InvalidTimestamp));
        }

        if matches!(attributes.timestamp, jansu_sans_io::TimestampType::CreateTime)
            && timestamp > batch.max_timestamp
        {
            return Err(Error::Api(ErrorCode::InvalidTimestamp));
        }

        let encoded_size = record.size_in_bytes().map_err(|error| {
            debug!(?error);
            Error::Api(ErrorCode::CorruptMessage)
        })?;

        if record.length < 0 {
            return Err(Error::Api(ErrorCode::CorruptMessage));
        }

        // record.length excludes the varint length prefix itself.
        // size_in_bytes includes it, so this check should be implemented using
        // an exact helper in jansu-sans-io if VarInt prefix width is needed.
        if usize::try_from(record.length)
            .map(|record_length| record_length > encoded_size)
            .unwrap_or(true)
        {
            return Err(Error::Api(ErrorCode::CorruptMessage));
        }
    }

    Ok(())
}
```

That finishes the biggest correctness issue: accept valid compressed Kafka batches even when recompression would not be byte-identical, while still rejecting CRC/batch-length corruption before append.

## 3. Add request, batch, and record size enforcement

Phase 07 requires message sizes, request sizes, and record batch sizes. The stream layer has a frame-size concept, but `ProduceService` itself still needs stable Kafka error mapping for partition-level size failures. 

### Change: add Produce limits

**File:** `jansu-storage/src/service/produce.rs`

Add constants and helpers:

```rust
impl ProduceService {
    const DEFAULT_MAX_REQUEST_BYTES: usize = 100 * 1024 * 1024;
    const DEFAULT_MAX_BATCH_BYTES: usize = 100 * 1024 * 1024;
    const DEFAULT_MAX_RECORD_BYTES: usize = 1 * 1024 * 1024;

    fn batch_wire_size(batch: &deflated::Batch) -> Result<usize> {
        let length = usize::try_from(batch.batch_length)
            .map_err(|_| Error::Api(ErrorCode::CorruptMessage))?;

        length
            .checked_add(size_of::<i64>())
            .and_then(|size| size.checked_add(size_of::<i32>()))
            .ok_or(Error::Api(ErrorCode::CorruptMessage))
    }

    fn records_wire_size(records: &[Record]) -> Result<usize> {
        records
            .iter()
            .map(|record| {
                record
                    .size_in_bytes()
                    .map_err(|error| {
                        debug!(?error);
                        Error::Api(ErrorCode::CorruptMessage)
                    })
            })
            .try_fold(0usize, |acc, size| {
                acc.checked_add(size?).ok_or(Error::Api(ErrorCode::RecordListTooLarge))
            })
    }

    fn validate_batch_size(batch: &deflated::Batch) -> Result<()> {
        let batch_size = Self::batch_wire_size(batch)?;

        if batch_size > Self::DEFAULT_MAX_BATCH_BYTES {
            return Err(Error::Api(ErrorCode::RecordListTooLarge));
        }

        Ok(())
    }

    fn validate_record_sizes(records: &[Record]) -> Result<()> {
        for record in records {
            let size = record.size_in_bytes().map_err(|error| {
                debug!(?error);
                Error::Api(ErrorCode::CorruptMessage)
            })?;

            if size > Self::DEFAULT_MAX_RECORD_BYTES {
                return Err(Error::Api(ErrorCode::MessageTooLarge));
            }
        }

        Ok(())
    }
}
```

```rust
fn validate_request_size(&self, req: &ProduceRequest) -> Option<ErrorCode> {
    let Some(topics) = req.topic_data.as_deref() else {
        return None;
    };

    let mut size = 0usize;

    for topic in topics {
        if let Some(partitions) = topic.partition_data.as_deref() {
            for partition in partitions {
                if let Some(records) = partition.records.as_ref() {
                    for batch in &records.batches {
                        match Self::batch_wire_size(batch) {
                            Ok(batch_size) => {
                                let Some(next) = size.checked_add(batch_size) else {
                                    return Some(ErrorCode::RecordListTooLarge);
                                };

                                size = next;
                            }
                            Err(_) => return Some(ErrorCode::CorruptMessage),
                        }
                    }
                }
            }
        }
    }

    if size > Self::DEFAULT_MAX_REQUEST_BYTES {
        Some(ErrorCode::RecordListTooLarge)
    } else {
        None
    }
}
```

```rust
fn request_error_response(&self, req: ProduceRequest, error_code: ErrorCode) -> ProduceResponse {
    let responses = req.topic_data.map_or_else(Vec::new, |topics| {
        topics
            .into_iter()
            .map(|topic| self.topic_error(topic, error_code))
            .collect()
    });

    ProduceResponse::default()
        .responses(Some(responses))
        .throttle_time_ms(Some(0))
        .node_endpoints(None)
}
```

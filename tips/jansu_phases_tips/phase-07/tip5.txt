## Phase 07 status after reading the plan and code

Phase 07 is **not ready to mark complete yet**, but it is close. The current implementation is already more than a stub: Produce is routed, validates batches before append, handles `acks=0` suppression, has storage and broker tests, and has ledger entries. The blocker is that it remains unadvertised and ledgered as partial because the project requires proof before compatibility claims: MASTER_PLAN/AGENTS require phase-backed work, focused and broader tests, attempt logs, canonical phase log updates, ledger proof, and audit updates before a phase can be considered done.  

The exact open issue is AUDIT-003: Produce is routed but must stay unadvertised until stable client or differential proof is recorded in the compatibility ledger.  Phase 07’s own phase file requires Kafka-exact normal Produce semantics for `acks=0/1/all`, invalid acks, topic/partition/auth failures, request/message/batch sizes, timestamps, magic, CRC, compression, per-partition errors, schema validation safety, quota/throttle hooks, and client proof with Java and librdkafka.  The current phase log says prior work already added batch validation, metadata prevalidation, CRC checks, positive gzip/lz4/zstd tests, storage mutation safety, broker v0..11 decode tests, and `acks=0` suppression, but it remains pre-advertisement due missing Java/librdkafka proof. 

The most important new finding is a protocol-version gap: the repo’s `ProduceRequest.json` and `ProduceResponse.json` currently stop at `validVersions: "0-11"`, but the official Kafka 4.2 protocol includes Produce v12 and v13, with v13 switching topic addressing to `topic_id => UUID`.   ([Apache Kafka][2]) That means a “100% Kafka 4.2 replacement” claim cannot close Phase 07 honestly unless we either update the descriptors through v13 or explicitly cap the compatibility claim to Produce v0..11. My recommendation is to update to v13 and advertise Produce only after the full test/client matrix passes.

## Phase 07 definition of done

Phase 07 should be declared complete only when all of this is true:

1. `ProduceRequest` and `ProduceResponse` descriptors cover Kafka 4.2 Produce v0..13, including v13 topic UUIDs.
2. `ProduceService` is Kafka-exact for non-transactional, non-idempotent Produce across v0..13.
3. Java and librdkafka producer tests pass with `enable.idempotence=false`, because modern Kafka Java producers default idempotence to true and Phase 11 owns durable idempotent producer semantics. Kafka producer docs say idempotence is enabled by default when configs do not conflict, and idempotence requires `acks=all`, retries, and bounded in-flight requests. ([Apache Kafka][3])
4. Any transactional or idempotent Produce path that is not Phase-07-certified returns a safe Kafka error instead of silently accepting data with weaker semantics.
5. Snappy is accepted for valid producer batches. Kafka’s message format explicitly lists compression bits `0..4` as none/gzip/snappy/lz4/zstd, and records are compressed as full batches. ([Apache Kafka][4])
6. CRC validation is performed over the original wire batch bytes, not by re-compressing records and comparing against a canonical local encoding. This is crucial: re-compression can differ across Java/librdkafka/Rust codecs while still being Kafka-valid.
7. Oversized requests and batches map to Kafka errors. Kafka documents `socket.request.max.bytes` as 104,857,600 bytes and `message.max.bytes` as 1,048,588 bytes in current broker config docs. ([Apache Kafka][5])
8. Produce is added to `advertised_versions()` only after the ledger row is updated and the compatibility contract passes. The broker currently advertises only ApiVersions and Metadata, while routing Produce internally.

### 3. Refactor ProduceService around version-independent topic identity

Current `ProduceService` uses `topic.name` directly, so v13 topic UUIDs cannot work.  Add a resolver that accepts either name or topic ID, asks storage metadata for the canonical topic, and returns the name needed by `Topition`.

Patch shape for `jansu-storage/src/service/produce.rs`:

```rust
use std::collections::BTreeSet;

use jansu_sans_io::{
    Ack, ApiKey, BatchAttribute, ErrorCode, MaximumAllocationSize as _,
    ProduceRequest, ProduceResponse,
    produce_request::{PartitionProduceData, TopicProduceData},
    produce_response::{
        BatchIndexAndErrorMessage, PartitionProduceResponse, TopicProduceResponse,
    },
    record::{Record, deflated},
};

use crate::{Error, Result, Storage, StorageFeature, TopicId, Topition};

#[derive(Clone, Copy, Debug)]
struct ProduceLimits {
    socket_request_max_bytes: usize,
    message_max_bytes: usize,
}

impl Default for ProduceLimits {
    fn default() -> Self {
        Self {
            socket_request_max_bytes: 104_857_600,
            message_max_bytes: 1_048_588,
        }
    }
}

#[derive(Clone, Debug)]
struct ResolvedProduceTopic {
    name: String,
    topic_id: Option<[u8; 16]>,
    partition_indexes: BTreeSet<i32>,
    unknown_error: ErrorCode,
}

impl ProduceService {
    const MAGIC_V2: i8 = 2;

    fn response_topic_base(
        &self,
        name: Option<String>,
        topic_id: Option<[u8; 16]>,
    ) -> TopicProduceResponse {
        let mut response = TopicProduceResponse::default();

        // After descriptor regeneration, Name is valid for v0..12 and TopicId is
        // valid for v13+. The serializer will emit only fields valid for the
        // negotiated response version, so setting both when known is safe.
        response = response.name(name);
        response = response.topic_id(topic_id);

        response
    }

    fn partition_error_with_message(
        &self,
        index: i32,
        error_code: ErrorCode,
        batch_index: Option<i32>,
        message: Option<String>,
    ) -> PartitionProduceResponse {
        let record_errors = batch_index
            .map(|batch_index| {
                vec![BatchIndexAndErrorMessage::default()
                    .batch_index(batch_index)
                    .batch_index_error_message(message.clone())]
            })
            .unwrap_or_default();

        PartitionProduceResponse::default()
            .index(index)
            .error_code(error_code.into())
            .base_offset(-1)
            .log_append_time_ms(Some(-1))
            .log_start_offset(Some(0))
            .record_errors(Some(record_errors))
            .error_message(message)
            .current_leader(None)
    }

    fn partition_error(&self, index: i32, error_code: ErrorCode) -> PartitionProduceResponse {
        self.partition_error_with_message(index, error_code, None, None)
    }

    fn map_storage_error(&self, index: i32, error: Error) -> PartitionProduceResponse {
        match error {
            Error::Api(error_code) => self.partition_error(index, error_code),
            Error::Schema(_) => self.partition_error(index, ErrorCode::InvalidRecord),
            other => {
                tracing::warn!(?other, "produce storage failure");
                self.partition_error(index, ErrorCode::UnknownServerError)
            }
        }
    }

    fn topic_error(&self, topic: TopicProduceData, error_code: ErrorCode) -> TopicProduceResponse {
        let partitions = topic.partition_data.map_or_else(Vec::new, |partitions| {
            partitions
                .into_iter()
                .map(|partition| self.partition_error(partition.index, error_code))
                .collect()
        });

        self.response_topic_base(topic.name, topic.topic_id)
            .partition_responses(Some(partitions))
    }

    async fn resolve_topic<G>(
        &self,
        ctx: &rama::Context<G>,
        topic: &TopicProduceData,
    ) -> Result<ResolvedProduceTopic>
    where
        G: Storage,
    {
        let (topic_key, unknown_error) = match (topic.name.as_deref(), topic.topic_id) {
            (Some(name), _) => (TopicId::from(name), ErrorCode::UnknownTopicOrPartition),
            (None, Some(topic_id)) => (TopicId::from(topic_id), ErrorCode::UnknownTopicId),
            (None, None) => return Err(Error::Api(ErrorCode::InvalidRequest)),
        };

        let metadata = ctx
            .state()
            .metadata(Some(&[topic_key]))
            .await
            .map_err(|error| match error {
                Error::Api(error_code) => Error::Api(error_code),
                other => {
                    tracing::warn!(?other, "metadata lookup failed during produce");
                    Error::Api(ErrorCode::UnknownServerError)
                }
            })?;

        let topic_meta = metadata
            .topics()
            .iter()
            .find(|candidate| candidate.error_code == i16::from(ErrorCode::None))
            .ok_or(Error::Api(unknown_error))?;

        let name = topic_meta
            .name
            .clone()
            .ok_or(Error::Api(unknown_error))?;

        let partitions = topic_meta
            .partitions
            .as_deref()
            .ok_or(Error::Api(unknown_error))?
            .iter()
            .map(|partition| partition.partition_index)
            .collect::<BTreeSet<_>>();

        Ok(ResolvedProduceTopic {
            name,
            topic_id: topic_meta.topic_id,
            partition_indexes: partitions,
            unknown_error,
        })
    }

    fn validate_batch(
        &self,
        batch_index: usize,
        batch: &deflated::Batch,
        limits: ProduceLimits,
        producer_state_enabled: bool,
        transactions_enabled: bool,
    ) -> Result<Vec<Record>> {
        let attribute = BatchAttribute::try_from(batch.attributes).map_err(|error| match error {
            jansu_sans_io::Error::UnknownCompressionType(_) => {
                Error::Api(ErrorCode::UnsupportedCompressionType)
            }
            other => Error::from(other),
        })?;

        if batch.magic != Self::MAGIC_V2 {
            return Err(Error::Api(ErrorCode::InvalidRecord));
        }

        if batch.wire_size()? > limits.message_max_bytes {
            return Err(Error::Api(ErrorCode::MessageTooLarge));
        }

        if batch.is_control() {
            return Err(Error::Api(ErrorCode::InvalidRecord));
        }

        if batch.is_transactional() && !transactions_enabled {
            return Err(Error::Api(ErrorCode::InvalidTxnState));
        }

        if batch.is_idempotent() && !producer_state_enabled {
            return Err(Error::Api(ErrorCode::UnknownProducerId));
        }

        if batch.base_timestamp < 0
            || batch.max_timestamp < 0
            || batch.max_timestamp < batch.base_timestamp
        {
            return Err(Error::Api(ErrorCode::InvalidTimestamp));
        }

        batch
            .validate_crc()
            .map_err(|_| Error::Api(ErrorCode::CorruptMessage))?;

        let records = Vec::<Record>::try_from(batch).map_err(|error| {
            tracing::debug!(?error, batch_index, "failed to inflate record batch");
            Error::Api(ErrorCode::CorruptMessage)
        })?;

        if records.is_empty() {
            return Err(Error::Api(ErrorCode::InvalidRecord));
        }

        if batch.record_count != u32::try_from(records.len())? {
            return Err(Error::Api(ErrorCode::InvalidRecord));
        }

        if batch.last_offset_delta != i32::try_from(records.len() - 1)? {
            return Err(Error::Api(ErrorCode::InvalidRecord));
        }

        for (index, record) in records.iter().enumerate() {
            if record.offset_delta != i32::try_from(index)? {
                return Err(Error::Api(ErrorCode::InvalidRecord));
            }

            let timestamp = batch
                .base_timestamp
                .checked_add(record.timestamp_delta)
                .ok_or(Error::Api(ErrorCode::InvalidTimestamp))?;

            if timestamp < 0 || timestamp > batch.max_timestamp {
                return Err(Error::Api(ErrorCode::InvalidTimestamp));
            }
        }

        let _ = attribute;
        Ok(records)
    }
}
```

Then change the partition path so it validates every batch in the partition before appending any batch in that partition:

```rust
async fn partition<G>(
    &self,
    ctx: &rama::Context<G>,
    transactional_id: Option<&str>,
    resolved: &ResolvedProduceTopic,
    partition: PartitionProduceData,
) -> PartitionProduceResponse
where
    G: Storage,
{
    if !resolved.partition_indexes.contains(&partition.index) {
        return self.partition_error(partition.index, resolved.unknown_error);
    }

    if transactional_id.is_some()
        && !ctx.state().capabilities().supports(StorageFeature::Transactions)
    {
        return self.partition_error(partition.index, ErrorCode::InvalidTxnState);
    }

    let Some(records) = partition.records else {
        return self.partition_error(partition.index, ErrorCode::InvalidRecord);
    };

    let producer_state_enabled = ctx
        .state()
        .capabilities()
        .supports(StorageFeature::ProducerState);

    let transactions_enabled = ctx
        .state()
        .capabilities()
        .supports(StorageFeature::Transactions);

    let limits = ProduceLimits::default();

    for (batch_index, batch) in records.batches.iter().enumerate() {
        if let Err(error) = self.validate_batch(
            batch_index,
            batch,
            limits,
            producer_state_enabled,
            transactions_enabled,
        ) {
            let error_code = match error {
                Error::Api(error_code) => error_code,
                Error::Schema(_) => ErrorCode::InvalidRecord,
                _ => ErrorCode::UnknownServerError,
            };

            return self.partition_error_with_message(
                partition.index,
                error_code,
                Some(i32::try_from(batch_index).unwrap_or(i32::MAX)),
                Some(error_code.to_string()),
            );
        }
    }

    let topition = Topition::new(resolved.name.clone(), partition.index);
    let mut base_offset = None;

    for batch in records.batches {
        match ctx.state().produce(transactional_id, &topition, batch).await {
            Ok(offset) => {
                let _ = base_offset.get_or_insert(offset);
            }
            Err(error) => return self.map_storage_error(partition.index, error),
        }
    }

    base_offset.map_or_else(
        || self.partition_error(partition.index, ErrorCode::InvalidRecord),
        |base_offset| {
            PartitionProduceResponse::default()
                .index(partition.index)
                .error_code(ErrorCode::None.into())
                .base_offset(base_offset)
                .log_append_time_ms(Some(-1))
                .log_start_offset(Some(0))
                .record_errors(Some(vec![]))
                .error_message(None)
                .current_leader(None)
        },
    )
}
```

And change `serve()` to validate request size, validate acks through the `Ack` enum, resolve topics once, then process partitions:

```rust
impl<G> rama::Service<G, ProduceRequest> for ProduceService
where
    G: Storage,
{
    type Response = ProduceResponse;
    type Error = Error;

    async fn serve(
        &self,
        ctx: rama::Context<G>,
        req: ProduceRequest,
    ) -> Result<Self::Response> {
        let limits = ProduceLimits::default();

        if req.maximum_allocation_size()? > limits.socket_request_max_bytes {
            return Ok(self.invalid_request_sized_response(req, ErrorCode::InvalidRequest));
        }

        let _ack = match Ack::try_from(req.acks) {
            Ok(ack) => ack,
            Err(_) => return Ok(self.invalid_acks_response(req)),
        };

        let mut responses = Vec::with_capacity(req.topic_data.as_ref().map_or(0, Vec::len));

        if let Some(topics) = req.topic_data {
            for topic in topics {
                let resolved = match self.resolve_topic(&ctx, &topic).await {
                    Ok(resolved) => resolved,
                    Err(Error::Api(error_code)) => {
                        responses.push(self.topic_error(topic, error_code));
                        continue;
                    }
                    Err(other) => {
                        tracing::warn!(?other, "produce topic resolution failed");
                        responses.push(self.topic_error(topic, ErrorCode::UnknownServerError));
                        continue;
                    }
                };

                let mut partition_responses = Vec::new();

                if let Some(partition_data) = topic.partition_data {
                    for partition in partition_data {
                        partition_responses.push(
                            self.partition(
                                &ctx,
                                req.transactional_id.as_deref(),
                                &resolved,
                                partition,
                            )
                            .await,
                        );
                    }
                }

                responses.push(
                    self.response_topic_base(Some(resolved.name), resolved.topic_id)
                        .partition_responses(Some(partition_responses)),
                );
            }
        }

        Ok(ProduceResponse::default()
            .responses(Some(responses))
            .throttle_time_ms(Some(0))
            .node_endpoints(None))
    }
}
```

The exact helper `invalid_request_sized_response` should mirror `invalid_acks_response` and return a per-partition error response. For request-size overflow, Kafka parity should be checked against the differential harness; my first mapping would be `InvalidRequest` for full request too large and `MessageTooLarge` for a partition batch over `message.max.bytes`.
